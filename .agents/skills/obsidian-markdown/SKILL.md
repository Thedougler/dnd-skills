# Obsidian Flavored Markdown

Syntax mechanics for pages in this vault. The TTRPG frontmatter spine
lives in `AGENTS.md` / `CONTEXT.md`. Callout **types** live in
`CONTEXT.md` (DM visual language) and `_system/references/creative-writing.md`.
Spoken `[!narration]` is `theatre-of-the-mind`.

Internal links are wikilinks. The vault form is
`[[kind.slug|Display Name]]`.

## What you need

| Need | Read |
|------|------|
| Wikilink, alias, heading, block, embed | `references/wikilinks-embeds.md` |
| Callout punctuation (`>` / `[!type]` / collapse) | `references/callouts-syntax.md` |
| Highlight, math, mermaid, footnote | `references/formatting.md` |
| Table pipes, tags, dates, HTML, callout breaks | `references/gotchas.md` |

## Workflow

### 1. Name the construct

Wikilink, embed, callout fence, mermaid, math, or footnote.

**Complete when** exactly one construct is identified.

### 2. Load the matching reference

Read only the file for that construct.

**Complete when** the syntax in play is the one in that file.

### 3. Write in this vault's form

Kind-prefixed stems. Alias for display. Callout type chosen from the
owners above, not invented here.

**Complete when** the written syntax matches the reference and the
owners this skill points at.

## Out of scope

Frontmatter `id` / `kind` / `canon` / `audience` spine. Callout type
selection. Player-facing prose. Leaflet, Fantasy Statblocks, Bases, and
Canvas plugin fences — those have their own skills or docs.
