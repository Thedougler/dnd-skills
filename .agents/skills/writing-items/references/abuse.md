# Abuse pass

Actively try to break the item. Patch real failure modes. Keep clever
uses that create memorable play without collapsing future challenges.

- Can it be spammed outside initiative?
- Can allies rotate it to bypass a per-creature limit?
- Can multiple copies stack?
- Does a familiar, summon, hireling, mount, or object use create multiplication?
- Does forced movement, teleportation, storage, or extradimensional space produce an exploit?
- Can it generate unlimited money, materials, spell slots, healing, information, or permanent minions?
- Does it remove concentration, action, component, or resource costs from an effect whose balance depends on them?
- Does a critical hit, Extra Attack, multi-target feature, or on-hit rider multiply its damage unexpectedly?
- Does it invalidate another PC's core specialty?
- Does it bypass the campaign's recurring obstacles so completely that interesting plans stop mattering?
