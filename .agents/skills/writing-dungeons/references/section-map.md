# Section map

Fill the schema's existing sections. Do not add a parallel outline.

`locations:` on other kinds still targets `kind: location`. Wikilink
other spatial kinds in the body and in geography fields. Rooms stay in
the Room Index unless a room needs independent geography or reuse
outside the dungeon — then mint a `location` via `writing-places`.

## Write

| Section | Own |
|---|---|
| Overview | Spoken mental model via `theatre-of-the-mind`: silhouette of the whole hole, dominant landmark, one non-visual signature, approaches. Stop at a reaction point. |
| Purpose | Original function, present state, why the party would enter. |
| Atmosphere | One signature, how visibility works, one recurring motif. DM scan — not a three-sense dump and not spoken. |
| Key Features | Dungeon-wide elements that affect multiple rooms. Each: obvious / reveals / logic / consequence. |
| Room Index | Numbered rooms. Significant rooms: location method inline (≥3 combining affordances). Connective rooms: exits plus one cue. Entry narration via `theatre-of-the-mind`. |
| Faction Presence | Typical control and wants as Knowledge. Link factions. Tonight's alert state is Work. |
| Secrets | Overarching hidden place truth. |
| Treasure | Links to notable `item` nodes and where they sit. Not a loot parcel list. |
| Resolution | Durable place change only — floods, collapses, reoccupation as a type. |

## Do not author

- wandering encounter tables or tonight's roster
- `difficulty` or `estimated_sessions` as required truth
- loot parcels without item nodes when the object must be cited
- victory scripts or predicted party routes
- encounter staging (counts, morale, tonight's tactics)
- trap/trial full mechanics when the challenge needs its own page
